## Current accepted facts
- Persian-first, bilingual storefront.
- Premium technology and gaming focus.
- Priority ecosystems: Apple, PlayStation/Sony, Xbox/Microsoft, Nintendo, Meta/XR.
- Hybrid brand experience: common AvanTech core with controlled brand-specific visual layers.
- SEO is a first-class requirement.
- Iranian commerce compatibility must include future-ready Enamad, Torob, payments, shipping, installments and SMS integration architecture.
- Product import from URL/Excel/manual sources is planned, but must be draft-first and source-aware.
- No-cost/low-cost infrastructure is a launch constraint.
- Google ecosystem is preferred where practical, but no vendor should force a later data rewrite.
